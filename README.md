# Kibble_Zurek_Mechanism_nanoscale

We have studied in depth the effects of the Kibble- Zurek mechanism for objects of extremely scales ( 20 and less lattice sites) and found out it that the solution of the SDEs describing the process are deviating from the statistical approach on the Mechanism. 

So far we have publised the following papers in which we discuss this disparity in depth : 

- https://www.lhscientificpublishing.com/journals/articles/DOI-10.5890-JVTSD.2024.06.002.aspx
- https://www.lhscientificpublishing.com/journals/articles/DOI-10.5890-JVTSD.2025.12.006.aspx

We will update this github repositary with code and comments on the code throughout our research on the subject.
